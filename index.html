⚖️ Ser vs Estar

SER = identité, définition
ESTAR = état, position

✅ SER pour :

  • Identité, nationalité, profession
  • Caractéristiques permanentes
  • Origine, heure, possession

✅ ESTAR pour :

  • Localisation (même permanente)
  • États temporaires
  • Émotions, santé
